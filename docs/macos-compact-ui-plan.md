# macOS 간결한 패널 UI 개선 계획

- 대상: 이슈 #2, PR #3. main 머지 없이 갱신 후 종료한다.
- 기준일: 2026-10-05
- 참고: Computer Use로 MonoCode 실제 화면을 확인했다. 배경 노출을 억제한 차분한 소재, 선명한 전경, 얇은 테두리와 간결한 컨트롤 배치를 참고한다. 해당 앱의 사용자 문서 내용은 변경하거나 공개하지 않는다.

## 이번 PR

- [x] PNG 표시 순서를 작게(9) → 균형(6) → 빠르게(3) → 압축 없음(0)으로 한다. JPEG의 최대 설정이 오른쪽인 방향과 맞춘다. PNG의 픽셀 품질은 모든 단계에서 동일하다. 기존 숫자·스냅샷은 유지한다.
- [x] 변환 시작과 주요 동작 버튼에 일관된 둥근 모서리 형태를 적용한다.
- [x] MonoCode 화면을 참고해 소재와 카드의 배경 노출을 억제하고 전경 텍스트 대비를 높인다. 투명도 줄이기·높은 대비 경로를 유지한다.
- [x] 변환 설정을 기본 접힘으로 구현한다. 접힘에는 형식·품질 또는 PNG 압축·저장 위치만 표시한다. 펼침에는 형식·품질 선택, 저장 위치 변경, 메타데이터·동일 이름 정책과 안내를 제공한다. 펼쳐도 예약된 작업 옵션은 바뀌지 않는다.
- [x] 우측 하단 앱 종료 버튼을 빨간색으로 표시한다.
- [x] 좌측 하단 클립보드 감지를 하나의 상태 버튼으로 통합한다. 켜짐·꺼짐 글자, 색·아이콘, 접근성 이름과 상태를 함께 제공한다.
- [x] 패널 기본 너비를 520 → 420, 높이를 650 → 600으로 조정한다. 빈 초기 화면은 스크롤 없이 표시하고, 선택 파일·긴 목록·펼친 설정은 스크롤로 접근한다. 좁은 크기에서도 컨트롤을 잘리지 않게 배치한다.
- [x] 실제 앱에서 접힘/펼침, PNG 순서와 수치, 대비·곡률·종료 색·감지 버튼, 초기 스크롤과 변환을 확인하고 Swift/Python·앱/DMG·macOS 15/26 CI 및 충돌 검증 후 PR을 갱신한다.
