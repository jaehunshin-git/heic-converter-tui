# macOS 간결한 패널 UI 개선 계획

- 대상: 이슈 #2, PR #3. 최신 사용자 확정 요구와 현재 구현과 검증 결과를 반영한다. 최종 CI·머지 상태는 PR 검사를 기준으로 한다.
- 기준일: 2026-10-06
- 상태: 최신 요구사항은 아래 “현재 PR #3 확정 기준”을 따른다. 이후의 완료 체크와 화면·빌드·CI 언급은 과거 개선 단계별 기록이며 이번 메뉴·저장/복사 기능의 검증 완료 근거가 아니다. 현재 기준은 기본 420×520pt·최소 380×520pt, 자동 높이, overlay 스크롤바, 드롭 영역 클릭 시 Finder 파일 선택창, 펼친 선택 글꼴 11pt, 정책 행 5:5 중앙 정렬과 작은 변경 버튼이다. 이전 펼친 UI 복원과 드롭 영역 클릭 붙여넣기는 이후 사용자 요청으로 대체됐다.
- 참고: Computer Use로 MonoCode 실제 화면을 확인했다. 배경 노출을 억제한 차분한 소재, 선명한 전경, 얇은 테두리와 간결한 컨트롤 배치를 참고한다. 해당 앱의 사용자 문서 내용은 변경하거나 공개하지 않는다.

## 현재 PR #3 확정 기준 (2026-10-06 요청, 2026-10-07 검증)

현재 구현의 기준이다. 이전의 단일 변환 시작 버튼, 지금 변환 문구, 클립보드 비변경 계약과 결과 복사 전체를 #6으로 미룬 범위는 이 기준으로 대체한다. 저장·복사 회귀와 앱·DMG 검증 결과는 `macos-verification.md`에 기록한다.

- 메뉴 막대 아이콘 왼쪽 클릭의 패널 토글은 유지한다. 오른쪽 클릭은 네이티브 `NSMenu`를 열어 패널 상태에 따른 “패널 열기”/“패널 숨기기”와 “앱 종료”를 제공한다. 패널 숨기기는 작업·감지를 유지하고 앱 종료와 구분한다.
- 하단의 큰 변환 시작 버튼을 50:50 너비의 “변환 후 저장”과 “변환 후 복사”로 나눈다. 기본 색은 파란색이며 클릭한 버튼만 1.5초 동안 초록색 체크로 요청 접수를 표시한 뒤 파란색으로 돌아온다. 임시 선택 목록에 파일만 있어도 두 버튼을 활성화한다. 누르면 임시 선택 목록과 대기 목록의 파일을 함께 해당 모드로 실행하거나 진행 중 작업 다음으로 예약한다. 드롭 직후 대기 목록에 먼저 추가하지 않고 원하는 모드를 직접 선택할 수 있다.
- 파일 저장 모드는 설정 폴더에 JPEG/PNG 결과를 저장한다. 복사 모드는 파일 URL 대신 이미지 자체를 복사하며 지정 저장 폴더에 결과를 남기지 않는다.
- 복사 작업은 worker가 작업별 임시 job 폴더에 결과를 출력하고 이미지 데이터(`imageData`)를 읽는 경로를 사용한다. 이미지마다 별도 `NSPasteboardItem`에 PNG/JPEG 원문과 TIFF 대체 표현을 준비하며 성공·취소·실패 완료 시 임시 결과를 정리한다. 기존 원본은 보존한다.
- 사용자가 복사 버튼을 명시적으로 선택한 작업만 worker의 `completed` 이벤트 이후 성공 결과를 클립보드에 쓴다. 드롭, Finder 선택, ⌘V 입력과 자동 감지만으로 변환하거나 결과를 복사하지 않는다. 파일 저장 모드와 감지·입력은 클립보드를 변경하지 않는다.
- 결과 0개, 취소 또는 예약·변환 중 다른 내용을 클립보드에 복사한 경우 현재 클립보드를 유지하고 복사하지 못한 이유를 안내한다. 이미지 데이터 준비 후 쓰기 직전에도 `changeCount`를 확인한다.
- 드롭 영역 클릭의 Finder 다중 파일 선택과 ⌘O, ⌘V는 유지한다. 임시 선택 목록의 실행 버튼은 현재 선택 모드에 따라 “지금 저장”/“지금 복사”로 표시하고 임시 선택 파일만 같은 모드로 실행하거나 예약한다. 하단 두 버튼의 선택·대기 목록 통합 실행과 구분한다. 대기 목록에 추가는 자동 실행하지 않는다.
- 재시도는 항목의 이전 저장·복사 모드를 유지한다. 예약 시 모드와 옵션 스냅샷을 고정하므로 이후 선택이나 설정 변경은 기존 예약에 영향을 주지 않는다.
- #6 후속 범위는 이미 저장된 결과 파일의 수동 복사와 결과의 휴지통 이동이다. 이번 PR의 변환 후 이미지 복사는 포함 범위이며 원본 삭제는 허용하지 않는다.

검증 대상은 오른쪽 메뉴와 왼쪽 토글, 기본·최소 너비에서 두 버튼의 배치와 기본 파란색과 클릭 직후 초록색 체크의 복귀, 각 모드의 JPEG/PNG 출력, 이미지 데이터와 TIFF 대체 표현, 임시 결과 정리, 클립보드 보존 조건, 선택 목록만 있을 때 하단 버튼 활성화와 선택·대기 목록 통합 실행, 지금 저장/지금 복사의 선택 목록 단독 실행, 재시도·예약 모드 및 옵션 유지다. 실행 결과는 별도로 기록한다.

## 드롭 영역 클릭 시 Finder 파일 선택 (2026-10-06)

- 패널 헤더는 “HEIC 파일을 JPEG · PNG로 변환”으로 표시한다.
- 파란 드롭 영역 클릭 또는 ⌘O로 표준 Finder 파일 선택창(`NSOpenPanel`)을 열고 여러 `.heic` 파일을 선택한다. 드래그 앤 드롭은 유지하며 문구도 파일 놓기 또는 클릭 선택을 안내한다.
- 선택 파일은 드롭과 동일한 임시 선택 목록에 추가한다. 사용자가 현재 선택 모드에 따라 지금 저장/지금 복사 또는 대기 목록에 추가를 선택하며 파일 선택만으로 변환하거나 결과를 복사하지 않는다.
- ⌘V 직접 붙여넣기와 자동 클립보드 감지는 유지한다. 드롭 영역 클릭은 클립보드를 읽지 않는다.
- 실제 동작과 회귀 검증 결과는 별도 검증 문서에 기록한다.
