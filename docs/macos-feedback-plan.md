## 이번 PR 구현 범위

- [x] 새 HEIC 클립보드 입력이 실제 대기 목록에 추가되면 메뉴 아이콘 아래 패널을 내려오는 느낌으로 표시한다. 이미 열린 패널은 닫지 않으며 포커스를 강탈하지 않는다. 중복·거절 입력, 시작 이전 클립보드, 감지 재개 시 기존 내용, 직접 붙여넣기는 자동 표시 이벤트를 만들지 않는다. 자동 변환하지 않는다. 모션 줄이기를 존중한다.
- [x] Glassmorphism 배경과 카드의 불투명도를 낮춰 뒤 화면이 더 보이게 한다. 텍스트·컨트롤은 흐리지 않으며 투명도 줄이기와 높은 대비에서는 가독성을 우선한다.
- [x] 신규 기본 저장 위치는 `~/Pictures/HEIC Converter`로 한다. 기존 사용자 선택 위치는 보존한다. 알려진 검증용 `/private/tmp/heic-converter-ui-check/converted` 설정만 신규 기본값으로 복구하고 사진 파일은 이동·삭제하지 않는다. 앱 화면은 홈 경로를 `~`로 표시한다.
- [x] JPEG Low(60)·Medium(80)·High(90)·Raw(100) 수치를 화면과 두 README에 설명한다. 품질 백분율이 아니며 Raw도 손실 JPEG라는 점을 유지한다.
- [x] PNG 압축은 압축 없음(0)·빠르게(3)·균형(6)·작게(9) 네 단계로 표시한다. PNG 화질은 동일하고 압축 시간·크기가 달라짐을 설명한다. 기존 저장 수치와 작업별 스냅샷, CLI/TUI는 유지한다. 네이티브 HDR PNG의 압축 설정 미적용 제한도 표시한다.
- [x] 선택한 파일과 대기 목록의 파일명 왼쪽에 이미지 썸네일을 표시한다. 작은 크기로 비동기 디코딩하고 메모리 캐시만 사용한다. 실패 시 대체 아이콘, 입력 제거·정리·종료 시 메모리 관리, 변환과 원본 독립 동작을 확인한다.
- [x] 클립보드 감지 켜짐을 파란색과 명시적 상태 글자로 표시한다. 접근 거부 상태는 따로 안내한다.
- [x] 저장 폴더 열기·앱 종료 버튼을 확대한다.
- [x] 대기 목록 변환 시작 버튼을 확대하고 가운데 정렬한다. 진행·취소와 보조 동작은 별도 행에 둔다.
